# Android 更新日志

本分支仅维护 LINUX DO 安卓客户端。按版本倒序整理，依据各标签间的 Git 提交、对应源码和可访问的 Release。当前源码版本为 `1.1.3+22`。

除 v1.1.0、v1.0.9 的日期已核对当前 fork 的 GitHub Release 外，其余日期均为标签指向提交的日期，不代表当前 fork 的发布时间。旧标签来自上游历史，不据此宣称旧安装包目前仍可下载。源码中的 `+N` 为构建基数；按 ABI 拆包后的 APK versionCode 可能带架构前缀。

## v1.1.3 · 2026-11-14

- 默认网络图片和缓存图片动态读取登录页同一代理设置，图片下载共用线路，且不向外部图片站附带论坛登录凭据。
- 启用代理时，默认网页入口使用应用内浏览器；工具页加载前等待代理生效，主页面连接失败时可自动换线或手动重试。
- 接口重试后仍返回 HTML、验证页或异常文本时，显示明确错误，避免 String 到 Map 的类型转换异常；修复验证 Cookie 同步和验证超时清理。
- 底部导航按实际按钮高度布局，保留安全区并额外留白，解决发布按钮和导航项目被裁掉、遮挡的问题。

本地 108 项测试与三架构 APK 构建通过，签名沿用旧版；手机真实订阅、Cloudflare 和系统导航栏表现仍需真机验收。下载见 [v1.1.3 Release](https://github.com/yuchen0x1/LINUX-DO/releases/tag/v1.1.3)。

## v1.1.2 · 2026-11-13

源码版本：`1.1.2+21`。覆盖升级沿用原签名，并递增构建号，兼容此前的本地测试包。

- 新增订阅链接导入，自动检测并选择可用节点，节点失效时切换；接口和网页登录共用代理，无需另填主机与端口。
- 点击“导入节点”即自动启用，失效时连续尝试剩余节点，直到连通；全部节点连接失败后停止循环并提示节点异常。
- 显示当前节点、延迟和全部失效提示，保留折叠的手动选项。订阅凭据加密保存在本机，全部节点失效时不静默直连，换线不自动重复提交发帖和回复。
- 首次打开不再显示需要逐页点击“下一步”的引导，改为约 1.2 秒的 Logo 启动动画，自动进入登录页。
- 后续冷启动也使用同一动画；保留已登录和游客模式直接进入首页的行为，返回键不会回到启动页。
- 未登录时跳过不必要的联网探测，系统要求减少动画时直接完成启动。
- 修复 Android 重新编码节点路径后无法加载部分订阅的问题；多个请求同时失败时，不会把已切换成功的新节点误判为失效。

支持包含 `proxies` 的 Clash / Mihomo YAML 订阅，最多 200 个节点、2 MB；不导入订阅内的远程路由、DNS 或监听设置。仅代理本应用的接口与 Android WebView，不修改系统代理。代理核心的许可和对应源码获取方式随安装包及 Release 提供，详见 [订阅代理说明](../SUBSCRIPTION_PROXY.md)。

## v1.1.1 · 2026-11-13

源码版本：`1.1.1+13`。本次为 Android 维护版本，保留 v1.1.0 的社区功能。

- 统一为仅维护 Android 的项目结构，移除其他平台的工程与构建入口，减少下载源码后的干扰。
- 补齐早期版本的更新记录，纠正草稿自动保存、DoH 接入及历史标签对应版本号的说明。
- 清理进入源码仓库的依赖输出、构建报告、过期原图和过程文件；本地签名、安装包与诊断材料继续独立保留。
- 修复固定构建环境无法满足现有依赖 SDK 要求的问题，对齐 Flutter 3.47.1 / Dart 3.13+；补齐 release 构建引用的 R8 配置文件。
- 增加上传边界检查，防止缓存、安装包、签名文件与非 Android 平台工程再次混入源码。
- release 包启用 Dart 混淆，调试符号单独保留，不作为 APK 下载附件公开。
- 修复 HTML 渲染依赖与 html 0.15.7 的选择器 API 不兼容问题，将必要的 MIT 许可补丁随仓库管理，避免只在本机缓存修复而使干净环境编译失败。
- 修复旧图片保存插件引用已移除 Flutter API 的编译问题，保留其 Android v2 插件实现和原有调用接口。

下载按设备架构选择 APK；跨版本覆盖安装以同一签名证书和递增的实际 versionCode 为准。包的 SHA-256 清单用于完整性核对，不替代 APK 签名认证。

## v1.1.0 · 2026-11-10

源码版本：`1.1.0+12`；标签提交：`f707d48`；对比范围：`v1.0.9..v1.1.0`。已核对 [GitHub Release](https://github.com/yuchen0x1/LINUX-DO/releases/tag/v1.1.0)，含 arm64-v8a、armeabi-v7a、x86_64 三种 Android APK。

### 新增

- 点击 LINUX DO 的帖子、用户、分类链接可跳转到对应页面，支持 `linuxdo://` 深链和冷启动链接暂存。
- 接收其他应用分享的文本：命中论坛帖子链接时打开帖子，否则进入发帖页并预填正文。
- 草稿在输入停顿约 3 秒后自动保存，离开发帖页也会触发保存；保留手动保存入口，恢复时避免覆盖已输入内容。
- 从 GitHub Releases 检查新版本并提供可信域名下载地址；属于版本发现与跳转下载，不是静默安装。
- 增加应用私有目录中的本地崩溃记录，不自动上传日志。

### 修复

- DoH 从设置开关接入实际 DNS 解析，修改网络配置后重建连接。
- 消息轮询改用服务端长轮询，失败时退避，进入后台暂停、回到前台恢复；通知包含事件摘要并支持点击跳转。
- 修复重复注册网络重试导致额外请求，以及会话失效时重复提示的问题。
- 修复主题换色后的组件样式回退、空帖子列表进入详情时越界、圆头像缺少尺寸时异常的问题。
- 修复自定义空状态文案不生效、错误页面插图错误和聊天背景路径错误的问题。

### 优化与兼容性

- 大图改为 WebP、按显示尺寸缩放；列表图片按目标尺寸解码，减少包内资源和解码开销。
- API Key 和 RSA 私钥优先存入 Android 系统密钥库并迁移旧数据；密钥库不可用时仍存在普通存储降级，因此不宣称所有情况下凭据都加密存储。
- 收窄备份范围并脱敏日志中的登录凭据。
- Android targetSdk 提升到 35，升级扫码与 Cronet 相关依赖，增加 16KB 原生库对齐检查。
- 三个当前本地 APK 的 SHA-256 与远端资产摘要一致。arm64 约 36.30 MiB、armv7 约 33.08 MiB、x86_64 约 38.82 MiB；不沿用历史文档中的“统一约 45 MB”数值。
- 上述功能按版本源码归档；真实账号、通知、网络与全设备行为仍需相应端到端验收，不能由标签存在推断已全部验证。
